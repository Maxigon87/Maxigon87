### 📌 Sobre mí

Desarrollador de software enfocado en crear aplicaciones que resuelven problemas cotidianos y optimizan procesos reales. Me especializo en el ecosistema **Flutter & Dart** para plataformas Windows, Android y Web, integrando interfaces modernas con servicios Cloud, bases de datos y arquitecturas escalables de punta a punta.

* 📱 **Desarrollo Multiplataforma:** Flutter & Dart (Desktop, Mobile y Web).
* 🔥 **Backend & BaaS:** Firebase (Firestore, Authentication, Storage).
* ☁️ **Cloud & Serverless:** Cloudflare (Workers, Pages, D1, R2).
* 🗄️ **Datos:** Sincronización Cloud, bases de datos locales y consumo de APIs REST.
* ⚙️ **DevOps & Metodología:** Git, GitHub, CI/CD y automatización.
